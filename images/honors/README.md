# Honors photos

Place award, event, or certificate photos in this folder. The Honors page is already designed with a sticky preview panel; once the final photos are available, add a `data-image` attribute to the corresponding honor row in `honors.html`, for example: `data-image="images/honors/phi-tau-phi.webp"`.

Recommended export: WebP or JPEG, landscape 4:3, at least 1200 x 900 px, under 400 KB per image.
